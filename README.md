# Backlight

Приложение для строки меню macOS, которое управляет USB-подсветкой монитора ROBOBLOQ («ZX sync led strip», VID `0x1A86`, PID `0xFE07`). Заменяет SyncLight.

Лента не хранит цвет: при каждой подаче питания она включает радугу. Поэтому Backlight живёт в строке меню (без Dock), стартует при входе в систему и сам отправляет выбранный цвет:
- когда лента подключается (включение Mac, переподключение кабеля);
- когда Mac просыпается.

## Сборка

```bash
./build.sh           # собрать build/Backlight.app
./build.sh install   # собрать, положить в ~/Applications и запустить
```

## Протокол (по коду SyncLight 2.20.1)

HID output report 64 байта на интерфейсе с usage page `0xFF00`:

```
"RB" | длина пакета | номер (1…254) | команда | данные… | сумма всех предыдущих байт mod 256
```

| Команда | Код | Данные |
|---|---|---|
| Информация | `0x82` | — (ответ: id `[5..7]`, дюймы `[8]`, число LED `[11]`, прошивка `[21..23]`) |
| Цвет участка | `0x86` | группы по 5 байт: `начало, R, G, B, конец` (`254` = до конца) |
| Яркость | `0x87` | `5…255` |
| Эффект | `0x85` | `тип, индекс` |
| Отключить «открытие URL» | `0x93` | `0` |
| Выключить | `0x97` | — |

SyncLight по умолчанию включает «USB Power Optimization»: держит R+G+B ≤ 255, чтобы лента брала меньше тока от USB. Белый тогда `(85, 85, 85)`. В Backlight это так же по умолчанию, а переключатель «Полная яркость» отправляет цвет без ограничения, например `(255, 255, 255)`.
